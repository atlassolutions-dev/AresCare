# AresCare

Ahorros con calma para el cuidado de Ares. Cada proceso de la operación tiene su propia meta, se pueden agregar más, y todo queda guardado en el teléfono.

## Correrla

```bash
flutter pub get
flutter run
```

En Windows, si Flutter pide el Modo de desarrollador para los plugins, actívalo en Configuración > Sistema > Para programadores.

## La foto de Ares

El retrato del centro usa `assets/images/ares.jpg`. Si cambias esa foto, vuelve a correr la app.
